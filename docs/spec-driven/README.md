# Spec-driven workflow

Use this folder whenever you add a new feature.

## Recommended flow

1. Create a new feature folder under [features/](/Users/danielthrasher/projects/puppy-training-coach/docs/spec-driven/features).
2. Start with `spec.md`
3. Break the work into `plan.md`
4. Track concrete coding steps in `implement.md`
5. Build, test, and then update the files with what changed

## File roles

- [feature-template.md](/Users/danielthrasher/projects/puppy-training-coach/docs/spec-driven/feature-template.md): starting template for new work
- `spec.md`: user problem, goals, non-goals, acceptance criteria
- `plan.md`: technical approach, impacted files, rollout steps
- `implement.md`: actionable checklist while coding
